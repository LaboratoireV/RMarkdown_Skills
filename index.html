Four pieces, one publishing workflow.

Each tool has a distinct job. Understanding those boundaries makes reports easier to debug, reuse, and share. 每个工具各司其职；理解这些边界，会让报告更容易调试、复用与分享。

.Rmd

One source of truth

Keep explanation, code, and output instructions together so every render starts from the same documented analysis.

{r}

Intentional execution

knitr evaluates chunks in order and captures their text, tables, messages, and figures for the next stage.

tbl

A function, not a package

kable() is a table-formatting function exported by knitr. The full name is knitr::kable().

↗

Portable output

Pandoc converts the intermediate document into HTML, Word, PDF, or another format selected in YAML.
